# Source corpora

Inputs to the Ask Zero to One build that are not generated by this repo. The PDFs in these folders are git-ignored and must never be committed. This repository is public.

| Folder | Holds | Rule |
|---|---|---|
| `book/` | Exactly one PDF of *Zero to One* | Production builds need a licensed copy and `RAG_BOOK_LICENSED=true`. |
| `notes/` | The analyst's reading notes (PDF) | The analyst's own work. Whether client users may see them, and whether "My view" entries are shown, is decided before release. If a source file (Markdown or Word) exists, add it here too; it avoids extracting the corrections table from the PDF. |

`python -m rag manifest` records the hash of every file here in `build/manifest.json`, so each corpus release names exactly what it was built from.
