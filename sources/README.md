# Source corpora

Inputs to the Ask Zero to One build that are not generated by this repo. This repository is public.

| Folder | Holds | In git? | Rule |
|---|---|---|---|
| `book/` | Nothing the build uses | **No, never.** Git-ignored, so a local copy of the book (copyrighted) is never committed | The book is not part of the corpus. |
| `notes/` | The analyst's reading notes (PDF) | Yes | The analyst's own work, published by the analyst. If a source file (Markdown or Word) exists, add it here too; it avoids extracting the corrections table from the PDF. |

`python -m rag manifest` records the hash of every file here in `build/manifest.json`, so each corpus release names exactly what it was built from.
